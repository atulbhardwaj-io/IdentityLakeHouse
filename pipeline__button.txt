Pipeline Button (One-Command Runner)
====================================

File:
run_pipeline.ps1


Incremental Pipeline Commands
=============================

1) CSV -> Bronze incremental only (all tables)
.\run_pipeline.ps1 -RunCsvToBronze -SkipBronzeToSilver -BronzeTables all

2) CSV -> Bronze incremental + Bronze -> Silver incremental (all tables)
.\run_pipeline.ps1 -RunCsvToBronze -BronzeTables all -SilverTables all

3) Bronze -> Silver incremental only (all tables, no Bronze schema gate)
.\run_pipeline.ps1 -SilverTables all

4) CSV -> Bronze incremental + Bronze -> Silver incremental (one table)
.\run_pipeline.ps1 -RunCsvToBronze -BronzeTables demographic -SilverTables demographic

5) Bronze -> Silver incremental only (one table)
.\run_pipeline.ps1 -SilverTables demographic

6) Reload one table's incoming CSV files into Bronze only
.\run_pipeline.ps1 -RunCsvToBronze -SkipBronzeToSilver -BronzeTables demographic -ForceBronzeReprocess

7) Reload all incoming CSV files into Bronze only
.\run_pipeline.ps1 -RunCsvToBronze -SkipBronzeToSilver -BronzeTables all -ForceBronzeReprocess

8) Full Silver rebuild from Bronze (all tables)
.\run_pipeline.ps1 -SilverTables all -SilverLoadType full -SilverMode overwrite

Bronze Indicators
=================

Bronze row indicators:
- bronze_ingest_ts
- bronze_source_file
- bronze_batch_id

Bronze file manifest:
bronze_control.ingested_files

Check loaded files:
spark.sql("""
SELECT table_name, source_file_name, bronze_batch_id, row_count, status, bronze_ingest_ts
FROM bronze_control.ingested_files
ORDER BY bronze_ingest_ts DESC
""").show(truncate=False)

Check Bronze rows by batch:
spark.sql("""
SELECT bronze_batch_id, COUNT(*) AS rows
FROM bronze.demographic
GROUP BY bronze_batch_id
ORDER BY bronze_batch_id DESC
""").show(truncate=False)


Silver Indicators
=================

Silver row indicators:
- silver_processed_ts
- silver_run_id
- bronze_batch_id

Silver batch control table:
silver_control.processed_bronze_batches

Check Bronze batches processed into Silver:
spark.sql("""
SELECT table_name, bronze_batch_id, silver_run_id, input_rows, output_rows, status, processed_ts
FROM silver_control.processed_bronze_batches
ORDER BY processed_ts DESC
""").show(truncate=False)

Check Silver quality validation reports:
spark.sql("""
SELECT validation_run_id, table_name, validation_scope, status, total_rows, valid_rows,
       invalid_rows, rule_summary_json, validation_ts
FROM silver_control.quality_validation_results
ORDER BY validation_ts DESC
""").show(truncate=False)

Check Silver rows by run and batch:
spark.sql("""
SELECT silver_run_id, bronze_batch_id, COUNT(*) AS rows
FROM silver.demographic_valid
GROUP BY silver_run_id, bronze_batch_id
ORDER BY silver_run_id DESC
""").show(truncate=False)


Expected Incremental Skip Signals
=================================

Run the same incremental command twice.

Bronze should print:
[SKIP] No new CSV files for <table>

Silver should print:
[SKIP] No new Bronze batches for <table>
