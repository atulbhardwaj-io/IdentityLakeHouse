PowerShell note:
Do not paste Linux multiline commands directly into Windows PowerShell.
Lines ending with \ are for bash inside the container, not for PowerShell.

Use one of these options from Windows PowerShell:

Option 1: start PySpark with the helper script
.\run_pyspark.ps1

Option 2: run directly from PowerShell in one command
docker exec -it spark-master /bin/bash -lc "mkdir -p /tmp/.ivy2/cache /tmp/.ivy2/jars && /opt/spark/bin/pyspark --master spark://spark-master:7077 --packages io.delta:delta-spark_2.12:3.0.0 --conf spark.jars.ivy=/tmp/.ivy2 --conf spark.sql.extensions=io.delta.sql.DeltaSparkSessionExtension --conf spark.sql.catalog.spark_catalog=org.apache.spark.sql.delta.catalog.DeltaCatalog --conf spark.sql.catalogImplementation=hive --conf spark.sql.warehouse.dir=/app/spark-warehouse --conf javax.jdo.option.ConnectionURL=jdbc:derby:;databaseName=/app/metastore_db;create=true"

Safe Silver Edit (use test path first, then promote)

Inside pyspark prompt (>>>), run step by step:

from pyspark.sql import functions as F

# Step 1: Read current Silver table
base = spark.read.format("delta").load("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid")

# Step 2: Apply changes in memory (example filter)
changed = base.filter(F.col("pincode").isNotNull())

# Step 3: Write to test table (safe, no change to main table)
changed.write.format("delta").mode("overwrite").save("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid_test")

# Step 4: Validate test table
test_df = spark.read.format("delta").load("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid_test")
base.count(), test_df.count()
test_df.show(5, truncate=False)

# Step 5: Promote test table to main Silver table (this will overwrite main)
test_df.write.format("delta").mode("overwrite").option("overwriteSchema","true").save("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid")

Continue Work on Existing _test file (iterative changes)

Inside pyspark prompt (>>>), run:

from pyspark.sql import functions as F

# Step 1: Load current test table
test_df = spark.read.format("delta").load("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid_test")

# Step 2: Apply next round of changes (example)
next_df = (
    test_df
    .filter(F.col("pincode").isNotNull())
    .dropDuplicates(["date", "state", "district", "pincode"])
)

# Step 3: Save back to same _test path
next_df.write.format("delta").mode("overwrite").option("overwriteSchema","true").save("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid_test")

# Step 4: Validate updated test table
test_df = spark.read.format("delta").load("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid_test")
test_df.count()
test_df.show(5, truncate=False)

# Step 5: Promote test table to main Silver table when final
test_df.write.format("delta").mode("overwrite").option("overwriteSchema","true").save("/app/scripts/silver_layer/aadhaar_voter_link_raw_valid")
